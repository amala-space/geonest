# Fork-safe public repository implementation plan

> **For Codex:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task.

**Goal:** Keep the web and Android code publishable while removing production
identity and local secrets from a fresh public repository.

**Architecture:** Use source-controlled neutral defaults plus local/CI
configuration overrides for Android and service identity. Git ignore rules
exclude credentials and generated state only; they do not exclude source,
documentation, or developer tooling needed to build and contribute.

**Tech stack:** Git, Gradle/Android, Capacitor, SvelteKit, Firebase, Vitest.

---

### Task 1: Define the public-repository boundary

**Files:**
- Modify: `.gitignore`
- Modify: `android/.gitignore`
- Modify: `android/app/.gitignore`
- Test: a fresh temporary Git repository created from the worktree

**Step 1: Write the failing boundary check**

Create a shell check that initializes a temporary repository from the source
tree and asserts that `android/app/google-services.json`, signing files, Android
`local.properties`, `.env`, `.firebaserc`, real `assetlinks.json`, Playwright
storage state, and `.firebase/` are absent; assert that Android Java/Kotlin
source, Gradle files, `docs/`, and `scripts/` are present.

**Step 2: Run it to verify it fails**

Run: `rtk bash scripts/verify-public-repository.sh`

Expected: fail while root `.gitignore` excludes `/android`, `docs`, and
`scripts`, or while a tracked identity file enters the temporary repository.

**Step 3: Implement the minimum boundary**

Remove broad `/android`, `docs`, and `scripts` patterns. Retain and anchor
secret/state patterns. Keep `android/app/google-services.json` ignored at its
actual path, and normalize the nested ignore files with a final newline.

**Step 4: Verify the boundary check passes**

Run: `rtk bash scripts/verify-public-repository.sh`

Expected: all source is present and each excluded file is absent.

### Task 2: Make Android identity configurable

**Files:**
- Modify: `android/app/build.gradle`
- Modify: `android/app/src/main/AndroidManifest.xml`
- Modify: `android/app/src/main/res/values/strings.xml`
- Modify: `capacitor.config.ts.example`
- Modify: `.env.example`
- Test: focused Gradle/configuration assertions

**Step 1: Write failing assertions**

Assert that tracked Android source has no production package name or host, and
that an Android package name and App Link host can be supplied through local
environment/Gradle properties.

**Step 2: Run assertions to verify failure**

Run the new boundary check. Expected: fail on the production application ID and
App Link host.

**Step 3: Implement neutral defaults and overrides**

Read Android identity from a documented Gradle property or environment variable,
defaulting to `com.example.geonest`. Supply the manifest host/path through
manifest placeholders. Keep the current production values only in ignored local
configuration/deployment infrastructure.

**Step 4: Verify a neutral debug build**

Run: `rtk npm run build && rtk npx cap sync android && rtk bash android/gradlew :app:assembleDebug`

Expected: exit 0 without `google-services.json` or a signing key.

### Task 3: Remove non-Android production identity

**Files:**

- Modify: `static/robots.txt`
- Modify: `static/sitemap.xml`
- Modify: `src/lib/seo.ts`
- Modify: relevant tests and deployment documentation

**Step 1: Write failing identity scan**

Extend the boundary check to reject the production domain, Firebase project ID,
production package, owner support address, and hard-coded allowed origins in
files intended for the public repository.

**Step 2: Run it to verify failure**

Run: `rtk bash scripts/verify-public-repository.sh`

Expected: fail on current owner-specific runtime and static files.

**Step 3: Implement a neutral public contract**

Use documented environment/build inputs for runtime identity; use neutral
templates or exclude deployment-only legal/SEO content from the public seed.
Do not expose a real production origin in function CORS configuration.

**Step 4: Verify public identity scan passes**

Run the boundary check. Expected: no production identity in exported files.
